# 対応範囲と制限

## 対応範囲

- Windows 11 タスクバー背景の透明・ぼかし・アクリル風効果
- タスクバー背景を標準状態に戻す操作
- 設定を `%APPDATA%\\WindowsUITransparency\\settings.json` に保存し、次回起動時に再適用
- タスクバーの子ウィンドウを列挙し、時計 `TrayClockWClass` とアプリアイコン領域 `MSTaskListWClass` が独立したHWNDとして存在する場合に不透明度変更を試みる
- ビルド済みEXEをユーザー単位の `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run` に登録・解除するスタートアップ設定
- GitHub ActionsでWindows用EXEをビルド

## 制限と注意点

1. `SetWindowCompositionAttribute` はMicrosoftが使用を推奨していないAPIで、将来のWindows更新で動かなくなる可能性があります。
2. 時計やアプリアイコン領域の個別透明度は、既知のウィンドウクラスが見つかった場合にだけ試行します。Windows 11のビルドによっては共有XAML/DirectComposition描画で、対象となる独立HWNDがなく制御できません。
3. アプリアイコンの個別制御は1つずつではなく、`MSTaskListWClass` が存在する場合にその領域全体を対象にします。
4. 個別ウィンドウのスタイルはアプリ終了時に元へ戻します。背景効果はそのままですが、個別透明度は必要に応じてアプリ起動時に再適用します。
5. スタートメニュー、クイック設定、通知センター、ウィジェットはこの初期版では変更しません。
6. 自動起動はEXE版のみで設定できます。HKCUのRunキーに登録するため通常管理者権限は不要です。EXE移動後は登録をやり直してください。
7. EXEはWindowsのGitHub Actionsランナーでビルドします。未署名のためSmartScreenが警告を表示する場合があります。

## 元に戻す

アプリでタスクバー背景を「通常に戻す」にします。時計・アイコン領域の不透明度を100%にして適用すると、検出されたウィンドウは標準スタイルに戻ります。
