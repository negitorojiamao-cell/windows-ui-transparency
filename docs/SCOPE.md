# 対応範囲と制限

## 初期版で対応する範囲

- Windows 11 のタスクバー背景に透明・ぼかし・アクリル風効果を適用
- 効果を通常状態に戻す
- Explorer 再起動でタスクバーのウィンドウハンドルが変化した場合、選択中の効果を再適用
- GitHub Actions で Windows 用 EXE をビルド

## 制限と注意点

1. タスクバー効果には SetWindowCompositionAttribute という、公開サポートが保証されない Windows API を利用します。Windows の更新で動作しなくなる可能性があります。
2. スライダーは色の濃さを調整しますが、すべてのモードで厳密な透明度を保証するものではありません。OS ビルドにより見え方が変わります。
3. アイコン・時計・通知領域の文字や画像そのものを透明化する機能ではありません。タスクバー背景の効果を変更します。
4. スタートメニュー、クイック設定、通知センター、ウィジェットは別々のシステム UI です。初期版では変更しません。
5. すべてのアプリのウィンドウ枠やタイトルバーを強制的に透明化することは、公開 API だけでは一律に実現できません。DWM の背景効果は基本的に個々のウィンドウ側が設定します。
6. EXE は Windows の GitHub Actions ランナーでビルドされます。未署名のため SmartScreen が警告を表示する場合があります。

## 元に戻す

アプリの「通常に戻す」を押してください。アプリを閉じるだけではタスクバーの表示を変更しません。

## 今後の候補

- Windows ビルド番号とタスクバー検出状態の表示
- 複数モニター環境でのテスト
- 起動時に効果を適用するオプション
- 対応可能な範囲での個別ウィンドウ向け背景効果の実験（システム全体に適用できる保証なし）
